# CS MARCHE

A curated marketplace for the CS community.

CS MARCHE is a lightweight marketplace where students can discover products, publish listings, and contact sellers directly through WhatsApp or phone.

## Planned stack

- Frontend: HTML, CSS, and vanilla JavaScript
- Backend: Node.js and Express
- Database: MongoDB with Mongoose
- Authentication: secure server-side sessions
- Image storage: Cloudinary (planned)

## Core features

- Single account type for every registered user
- Public product browsing
- Account registration and login
- Create, edit, and delete your own listings
- Product images and seller contact details
- WhatsApp and phone contact links
- Ownership checks and input validation

## Project status

Initial project setup.

## Security

Secrets are stored in environment variables and must never be committed. Production deployment must use HTTPS, secure cookies, restricted database credentials, and validated image uploads.
